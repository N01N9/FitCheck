### LoRA v1 중간 점검 (1,000 스텝) — base → 4스텝 증류 전이 실패
- 시범 16건, 증류 klein-4B(4스텝) + LoRA + 학습 지시문("[EXTRACT] ..."): 맞는 옷 첫 장 6%, 2장 중 19%. 표시 자국은 0%.
  대부분 초록 선만 지운 **입력 사진을 그대로 다시 그렸다.**
- 진단(학습 쌍 3 + 실험0 사진 2):
  - 증류 4스텝 + 학습 지시문: 5/5 입력 복사
  - 증류 4스텝 + 자연어 지시문(학습 없는 outline_dimcrop 문장): 상품 사진이 나오지만 초록 선이 일부 남음
  - base 30스텝 CFG 4 + 학습 지시문: 4/5 맞는 상품 사진, 초록 선 없음
- 해석: LoRA 는 base 에서 일을 배우고 있지만, 증류 모델이 모르는 새 지시문 형식의 학습은 4스텝 증류 모델로 옮겨 가지 않는다.
- 조치: (1) v1 평가는 base(20스텝, CFG 4)와 증류(학습 지시문·자연어) 세 조합으로 같은 90건에서 잰다.
  (2) v2 학습 쌍은 증류 모델이 이미 아는 자연어 지시문으로 만든다(`pairs --prompt-style natural`).

- 상품 컷(사람 없음)에 겉옷을 입히라 하면 klein 이 사람을 새로 지어냈다 → 단독 상의 모드는 사람이 입은 사진만 쓴다.
- 재킷 자리에 은행 재킷에 없는 색이 많으면(klein 이 안의 상의를 바꿔 그린 것) 거부한다. 재검사로 101 → 39.
- 이어 입히기는 한 장에서 이너 정답(은행 P)·겉옷 정답(은행 O)·벗기기 정답(교체 직후 사진)이 모두 실제 사진이다.

### LoRA v1
- 학습 쌍 2,847 (바닥 합성 1,919 / 그대로 두기 300 / 단독 상의 교체 166 / 벗기기 137 / 겉옷 추출 137 / 이어 입힌 이너 98 /
  겉옷 아래 이너 교체 90). 출처 가중치 swap 3, layer_inner 3, swap_solo 1.5, layer_outer 1.5, 나머지 1, identity 0.3.
- 3,000 스텝, rank 32, lr 1e-4. 한 스텝 4.7 s (은행 만들기와 동시에 돌 때 5.9 s).
- 알려진 흠: 같은 사진이 두 실행에 들어가 쌍 이름이 겹친 18쌍(겉옷 쌍의 약 7%)이 잘못 짝지어졌다. 이너 추출과는 무관.
  v2 부터는 쌍 이름에 실행 폴더를 넣고 겹치면 멈춘다.

### LoRA v1 중간 점검 (1,000 스텝) — base → 4스텝 증류 전이 실패
- 시범 16건, 증류 klein-4B(4스텝) + LoRA + 학습 지시문("[EXTRACT] ..."): 맞는 옷 첫 장 6%, 2장 중 19%. 표시 자국은 0%.
  대부분 초록 선만 지운 **입력 사진을 그대로 다시 그렸다.**
- 진단(학습 쌍 3 + 실험0 사진 2):
  - 증류 4스텝 + 학습 지시문: 5/5 입력 복사
  - 증류 4스텝 + 자연어 지시문(학습 없는 outline_dimcrop 문장): 상품 사진이 나오지만 초록 선이 일부 남음
  - base 30스텝 CFG 4 + 학습 지시문: 4/5 맞는 상품 사진, 초록 선 없음
- 해석: LoRA 는 base 에서 일을 배우고 있지만, 증류 모델이 모르는 새 지시문 형식의 학습은 4스텝 증류 모델로 옮겨 가지 않는다.
- 조치: (1) v1 평가는 base(20스텝, CFG 4)와 증류(학습 지시문·자연어) 세 조합으로 같은 90건에서 잰다.
  (2) v2 학습 쌍은 증류 모델이 이미 아는 자연어 지시문으로 만든다(`pairs --prompt-style natural`).

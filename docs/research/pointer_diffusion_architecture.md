# 환각이 출력 공간에서 불가능한 모델 — Pointer Diffusion (가칭 PIXPTR) 설계 (2026-10-07)

요구: 워크플로가 아니라 **신경망 구조 자체**가 환각을 막아야 한다. 생성 부분이 있어도 원본에 없는 내용을 만들 수 없어야 한다.

## 핵심 아이디어: 픽셀을 생성하지 말고 "포인터"를 생성한다
기존 생성 모델은 출력 픽셀 값 자체(RGB 또는 잠재값)를 만든다 → 어떤 색·글자든 만들 수 있다 = 환각 가능.
PIXPTR 의 마지막 층은 **출력 픽셀마다 원본(대상 물체) 픽셀 위의 확률 분포**를 낸다. 출력 색은 그 분포로 원본 픽셀 색을 섞은 값이다.

  out(p) = g(p) · Σ_q softmax_q( ℓ(p, q) ) · src(q)        q ∈ 대상 마스크 안의 원본 픽셀만
            └ 회색 명암(스칼라, 범위 제한)   └ 신경망이 내는 건 포인터 로짓 ℓ 뿐

- 신경망 출력 = 포인터 로짓 ℓ(p,q) 와 회색 명암 g(p) ∈ [g_min, g_max] 뿐. **RGB 를 내는 출력 머리가 없다.**
- 출력 색은 원본 픽셀들의 볼록 결합(convex combination) → 원본 색 범위 밖의 색이 수학적으로 나올 수 없다.
  명암은 1채널 곱이라 색상(hue)·채도 비율이 바뀌지 않는다.
- 키(q)는 **대상 마스크 안 픽셀로만 하드 마스킹** → 넥타이·겉옷·배경 픽셀은 가리킬 수 없다 → "없던 것 추가" 불가능.

## 구조

```
입력: 원본 이미지 I, 대상 마스크 M, 목표 지정(새 시점/평평한 상품/새 배경 위 자세 등 — 기하 조건)
                           ┌──────────────────────────────────────────────┐
 원본 인코더 E(I, M) ─▶ 키 K_q, 값 V_q = (원본 RGB, 위치)   ※ 값은 '특징'이 아니라 원본 픽셀 그 자체
                           │
 포인터 디퓨전 본체 (DiT) ─▶ 출력 격자 p 마다 질의 Q_p
   · 확산은 '포인터 장(field)' 공간에서 돈다: x_t = 출력 픽셀이 가리키는 원본 좌표(2D) + 가시성 로짓
   · 조건: E 의 특징, 목표 기하(실루엣·시점), 시간 t
                           │
 포인터 해석 층 (고정 연산, 학습 파라미터 거의 없음)
   ℓ(p,q) = ⟨Q_p, K_q⟩/τ − ‖ŷ_p − pos_q‖²/σ²      (예측 좌표 ŷ_p 근처를 강하게 선호 — 국소성)
   out(p) = g(p) · Σ_q softmax(ℓ) V_q.rgb
   + 'UNKNOWN' 키 하나: 어떤 원본 픽셀도 근거가 없으면 이 키를 가리킨다 → 값은 '모름' 표시(마스크 채널)
                           │
 출력: 결과 이미지 + 모름 지도(UNKNOWN 가중치) + 포인터 장(어디서 왔는지 추적 가능)
```

## 구조가 강제하는 성질 (학습과 무관하게 성립)
| 성질 | 이유 |
|---|---|
| 새 색을 만들 수 없음 | 출력 = 원본 픽셀 볼록 결합 × 회색 명암 |
| 다른 물체 내용을 넣을 수 없음 | 키를 대상 마스크로 하드 마스킹 |
| 글자·로고를 새로 쓸 수 없음 | 원본에 없는 글리프는 표현 불가. 포인터가 국소적으로 매끄러우면(아래 제약) 원본 글리프가 통째로 옮겨짐 |
| 모르는 부분을 지어내지 않음 | UNKNOWN 키 + 그 확률이 출력됨. 원본 근거가 약하면 UNKNOWN 이 이기도록 τ·σ 와 사전확률을 둔다 |
| 결과의 모든 픽셀이 출처를 가짐 | 포인터 장 = 감사 추적(provenance). 어떤 픽셀이 어디서 왔는지 보여 줄 수 있음 |

## 글자·무늬 보존을 더 강하게: 포인터 장의 위상 제약
- 포인터 장 ŷ 를 자유 2D 장이 아니라 **매끄러운 변형의 매개변수**로 낸다: 조각별 아핀(삼각 메시 꼭짓점) 또는 B-spline 계수.
  → 이웃 출력 픽셀은 이웃 원본 픽셀을 가리킨다(접힘·찢김 없음). 글자 획이 섞이거나 뒤집히지 않는다.
- 접힘을 허용해야 하는 곳(옷 주름이 펴지는 곳)은 야코비안 행렬식 > 0 을 구조로 보장(로그-야코비안 매개변수화).

## 생성 모델이 남아 있는 곳과 그 한계
- 디퓨전은 **"어디를 가리킬지"만 생성**한다. 틀리면 결과는 '원본의 엉뚱한 부분'이 되지 새 내용이 생기지는 않는다
  (예: 소매 자리에 몸판 천을 가져옴). 이건 형태 오류이고 사람이 즉시 알아본다 — 그럴듯한 가짜(환각)가 아니다.
- 원본에 전혀 없는 정보(뒷면 무늬, 가려진 로고)는 **만들 수 없다**. UNKNOWN 으로 남기거나, 원본의 같은 천(민무늬 부분)을
  가리켜 채운다. 즉 "추측"이 구조적으로 '반복·연장'으로 제한된다.
- 사실감: 원본 픽셀만 섞으므로 해상도·화질은 원본 한계. 새 조명은 회색 명암까지만.

## 기존 연구와의 관계
- NLP 의 copy/pointer network(Vinyals 2015, See 2017), 영상의 appearance flow / backward warping,
  attention-as-flow(Leffa) 와 같은 계열. 차이: (1) 확산을 포인터 장 공간에서 돌림, (2) 값이 특징이 아닌 원본 픽셀이라
  출력 공간이 원본 볼록 껍질로 제한, (3) 하드 마스크 키 + UNKNOWN 키로 '모름'을 1급 출력으로.
  이 조합을 상품 추출·재배치에 쓴 선행 사례는 찾지 못함(완전 조사는 아님).

## 학습 (구조가 안전을 보장하므로 학습은 '정확도'만 책임진다)
- 정답 포인터 장을 아는 데이터: 우리가 변형을 준 자기 재구성(물체를 휘고 가리고 조명 바꿈), 바닥 합성 쌍.
  → 포인터 장에 대한 직접 지도 + 최종 RGB 재구성 손실.
- 정답 포인터를 모르는 데이터(엔진 착용 쌍): RGB 손실만 — 포인터는 잠재 변수로 학습.
- UNKNOWN 보정: 일부러 가린 영역에서 UNKNOWN 확률이 높도록 지도.

## P0 실험 (GPU 허락 후, 작게)
256px, 본체 약 0.1~0.2B. 데이터: 은행 상품 + 자기 재구성 변형 10만 쌍. 비교: 같은 데이터·크기의 일반 RGB 디퓨전.
지표: 보이는 영역 ΔE00, 글자 OCR 일치, '원본에 없는 색' 비율(구조상 0 이어야 함), UNKNOWN 보정 정확도, 형태 IoU.

# v5 구조 전면 개편 — 글로 종류를 알려 주지 않는 모델 (2026-10-07)

요구: 사용자는 사진과 "이 옷"(터치 한 번 또는 자동 선택)만 준다. 종류·길이·핏을 글로 지정하지 않는다.

## 왜 바꾸나 (v4 진단, 잘 보이는 옷 240장 엄격 판정)
- 상의 77%, 겉옷 57%, 하의 약 10%, 원피스 약 20%. 하의는 긴 바지·치마를 거의 다 무릎 반바지로 그렸다.
- "하의"→"바지/치마"로 이름만 바꿔도 10%→30%. 학습 안 한 klein 은 길이·모양은 맞히지만 색·무늬를 지어냈다(36%).
- 즉 지금 구조는 **모양(실루엣)을 글 이름에 기대고**, 우리 학습은 **색·무늬는 살렸지만 모양 읽기를 망가뜨렸다**.
  모양과 겉모습을 한 모델이 한꺼번에, 글의 도움을 받아 정하는 것이 문제의 뿌리다.

## 새 구조: 모양과 겉모습을 나눈다

```
사진 + 대상 지정(터치/자동 마스크)
   │
   ├─▶ [A] 실루엣 예측기 (작은 모델, 글 없음)
   │       입력: 사진, 대상 마스크, Seer 패치 특징
   │       출력: 상품 실루엣 마스크(정면, 평평), 화면 비율(세로로 긴 바지·드레스는 세로 칸)
   │       = "핏 읽기": 길이·소매·어깨끈·밑단 모양·폭이 여기서 정해진다
   │
   ├─▶ [B] 정체성 토큰: Seer(C-RADIOv4 / DINOv3) 대상 영역 특징 → 어댑터 → 토큰 64개
   │
   └─▶ [C] 그리는 모델 (klein-4B 또는 QIE-2511 + LoRA, 지시문은 고정된 한 문장 — 종류 이름 없음)
           조건: 원본 사진 · 대상 확대 · [A] 실루엣(공간 조건) · [B] 토큰
           역할: 주어진 실루엣 안을 사진 속 옷의 색·무늬·글자로 채운다
   │
   └─▶ [D] 후처리: 보이는 무늬·글자 옮기기(RoMa, 확신 높은 곳만) + 조명 보정 색 맞춤
   └─▶ [E] 엄격 검증: 실루엣 일치(결과 마스크 vs [A]), 색 ΔE, 글자, VLM 체크리스트 → 실패면 다시 찍기 요청
```

### [A] 실루엣 예측기 — 이번 개편의 핵심
- 왜 따로: 하의·원피스 실패는 거의 다 모양 문제다. 모양은 작은 2D 마스크라 **작은 모델로 정확히 배울 수 있고 검증도 쉽다**
  (IoU 로 숫자 채점). 큰 생성 모델은 채우기만 하면 된다.
- 정답 데이터가 이미 있다: 은행 상품 1.8만 장의 앞면 마스크(`bank/front_mask`) = 정답 실루엣. 입력은 지금 엔진이 만드는
  착용 사진(교체·덧입힘)과 바닥 합성 장면 — 짝이 이미 있다. 종류 라벨이 필요 없다.
- 구조: 사진+마스크를 Seer 로 읽고(고정), 작은 디코더(UNet 또는 소형 DiT)로 256×256 실루엣 + 비율을 낸다. 1단계 학습은
  수 시간 규모.
- 사람이 고치기도 쉽다: 앱에서 실루엣이 이상하면 길이 슬라이더 같은 걸로 조정할 수 있는 여지(선택).

### [C] 그리는 모델 학습 방식
- 지시문은 항상 같은 문장("이 사진 속 표시된 옷을 이 모양의 상품 사진으로"). 종류 단어를 학습에서도 빼서, 모델이 글에 기대지 않게.
- 학습 때 실루엣 조건은 **정답 상품 마스크**를 쓰고(teacher forcing), 일부는 [A]의 예측 실루엣을 섞어 실제 오차에 강하게.
- 정답 상품은 비율 그대로 캔버스에 넣는다(긴 바지를 정사각형에 욱여넣지 않음) — v4 "칸 넓게 채우기" 버릇 제거.
- 데이터 균형: 하의·원피스 쌍을 상의만큼(은행에 바지·청바지 약 3,300, 원피스 약 1,500, 치마·반바지 포함 약 4,600).
- 손실: 실루엣 안쪽 가중↑, 실루엣 밖은 흰 배경 강제. Seer 정렬(REPA) 보조 손실.

### 대상 지정(글 대신)
- 앱: 사용자가 옷을 한 번 터치 → SAM 3(상업 가능) 로 마스크. 또는 자동으로 사진 속 옷을 모두 찾아 각각 만든다.
- 가림 비율·핵심 부위 가시성으로 "만들 수 있음 / 다시 찍기"를 판단(입력 조건).

## 기대 효과와 위험
- 하의·원피스: 실루엣을 따로 맞추면 형태 실패 대부분이 [A]로 옮겨 가고, [A]는 IoU 로 직접 개선 가능 → 10~20% → 상의 수준(70%+) 기대.
- 상의·겉옷: 소매 길이·조끼 소매·후드 유무가 실루엣으로 고정돼 일부 개선.
- 색(어두운 사진): 구조로는 안 풀림 → [D] 조명 보정 + 학습 데이터에 어두운 조명 증강(입력에만).
- 위험: [A]가 틀리면 그대로 틀린 모양으로 그린다 → [E]에서 [A]의 확신도·사진과의 일치를 따로 검사. 가려진 부분의 실루엣
  (예: 코트 밑단)은 추측이 남는다.

## 단계와 필요한 것 (GPU 는 허락 후)
1. (GPU 없음) 데이터: 은행 마스크 → 실루엣 정답, 엔진·바닥 쌍에 실루엣·비율 붙이기, 하의·원피스 엔진 계획, 비율 보존 캔버스
2. (GPU 짧게) [A] 학습 + IoU 평가(잘 보이는 옷 240장의 하의·원피스로 눈 판정 대신 숫자 확인 가능)
3. (GPU 1일) [C] 학습: klein + 실루엣 조건 + 고정 지시문 + Seer 토큰
4. 240장 + 바닥 60장 한 장 기준 엄격 판정

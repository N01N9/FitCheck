# 구조로 신뢰성을 강제하는 물체 추출·재배치 모델 (가칭 ASSET) — 설계 (2026-10-07)

목표: 사진 속 물체 하나를 그대로 떼어 와 (1) 다른 이미지에 붙이거나 (2) 다른 각도·모양(평평하게 편 상품 사진 등)으로 보여 준다.
"학습이 잘 되길 바라는" 것이 아니라 **구조가 원본 충실성을 강제**해야 한다.

## 설계 원칙 (불변식)
1. **보이는 부분의 색은 원본 픽셀에서만 온다.** 신경망은 "어디서 가져올지"(좌표)와 "얼마나 밝게"(명암)만 낸다.
   색상(hue)·채도를 새로 만들 출력 자체가 없다 → 색 바뀜·글자 지어내기가 구조적으로 불가능.
2. **물체를 먼저 '자산'(asset)으로 만들고, 결과는 그 자산을 렌더링한 것이다.** 생성 모델이 매번 새로 그리지 않는다.
3. **원본에 없던 부분(뒷면·가려진 곳)은 따로 표시된 영역에서만 채운다.** 그 영역의 출력은 원본 색 묶음(palette)으로 제한하고,
   확신도를 함께 낸다. 결과 이미지와 함께 "추측한 영역 지도"를 돌려준다.
4. **되돌리기 검사(cycle)가 구조에 들어 있다.** 자산을 원래 시점·자세로 렌더링하면 입력 사진의 보이는 픽셀과 같아야 한다.
   어긋나면 결과를 내지 않는다.

## 구조

```
사진 + 대상 지정(터치)
 │
 1. 분할: 대상 마스크(+ 가린 물체 마스크)                         [SAM 3 등, 고정]
 │
 2. 기하 추정: 대상의 모양 모델
     ├ 강체 물건: 단일 사진 3D (메시/가우시안) + 시점              [오픈 3D 복원 모델]
     └ 옷 같은 변형체: 2D/2.5D 변형 메시 (재단 도면 같은 평평한 기준 모양 ↔ 사진 속 모양)
 │
 3. 텍스처 자산 = 사진 픽셀을 기준 좌표(UV)로 '역투영'한 것      [신경망 아님, 기하 연산]
     · 각 텍셀: 색(원본에서 샘플) · 가시성(보였나) · 조명 성분 분리
     · 조명 분리: 색 = 반사율(albedo) × 명암(shading). 명암은 '회색 1채널'만 허용 → 색상이 못 바뀜
 │
 4. 빈 곳 채우기(가려진·뒷면 텍셀만)                               [작은 생성망, 출력 제한]
     · 입력: 보인 텍셀, 기하, 대칭·반복 패턴 단서
     · 출력: 원본 palette 가중합(+ 작은 잔차) → 원본에 없는 색을 못 만든다
     · 확신도 지도 함께 출력
 │
 5. 렌더링(결정적): 원하는 시점·자세·평평한 상태·새 배경/조명으로 자산을 그림   [미분 가능 렌더러, 신경망 아님]
     · 새 조명은 명암(회색)과 화이트밸런스(전역 3×3)만 바꿈
 │
 6. 마감(선택): 경계·그림자·미세 주름만 다듬는 작은 정제망
     · 제약: 보이는 영역 출력은 렌더 결과 ± 작은 범위(명암 위주)로 잘라 냄(clamp)
 │
 7. 검사: (a) 원래 시점 재렌더 vs 입력 사진(보이는 영역) (b) 추측 영역 비율 (c) 확신도
        → 통과 못하면 "다른 사진 필요"
 출력: 결과 이미지 + 추측 영역 지도 + 신뢰 점수
```

## 왜 고질적 문제가 사라지나
| 문제 | 기존 생성 모델 | ASSET |
|---|---|---|
| 색 바뀜 | 매번 새로 그림 | 색은 원본 샘플, 명암은 회색 1채널 → 색상 변경 불가 |
| 글자·로고 깨짐 | VAE 압축·재생성 | 픽셀 그대로 옮김(해상도는 원본 한계) |
| 없던 것 추가(넥타이 등) | 그럴듯하게 그려 넣음 | 분할로 가린 물체를 빼고, 빈 곳은 palette 제한 + 표시 |
| 모양·길이 바뀜 | 텍스트·버릇에 끌림 | 기하 모델이 정함, 재렌더 검사로 확인 |
| 모르는 걸 지어냄 | 표현 불가 | 추측 영역 지도 + 확신도로 명시 |
| 다른 각도 | 매번 다른 물체가 됨 | 같은 자산을 렌더링 → 각도마다 일관 |

## 대가와 한계
- **사실감의 상한은 기하 추정 품질**에 달려 있다. 단일 사진 3D·옷 변형 메시가 틀리면 결과가 틀린다(대신 재렌더 검사가 잡는다).
- 뒷면처럼 전혀 안 보인 곳은 여전히 추측이다 — 다만 숨기지 않고 표시한다.
- 투명·털·반사 재질은 '색 = 반사율 × 회색 명암' 모형이 맞지 않는다 → 별도 처리 또는 거절.
- 옷은 강체가 아니라서 "입은 모양 → 평평한 모양" 변형 메시가 핵심 난제다. 이 부분은 학습이 필요하다
  (기하만 학습, 색은 건드리지 않으므로 실패해도 색은 안 바뀐다).

## 무엇을 학습하고 무엇을 고정하나
| 부품 | 방식 | 학습 데이터 |
|---|---|---|
| 분할 | 기존 모델(SAM 3 등) | – |
| 강체 3D | 기존 오픈 모델(상업 라이선스 확인 후) | – |
| 옷 변형 메시(입은 → 평평) | **학습** | 우리 합성 짝(상품 마스크 ↔ 착용 마스크, 대응을 아는 바닥 합성) |
| 조명 분리 | 학습(작음) | 합성(알려진 명암을 곱한 데이터) |
| 빈 곳 채우기 | 학습(작음, palette 출력) | 자기 재구성(일부러 가린 텍셀 복원) |
| 렌더러·역투영·검사 | 결정적 코드 | – |

## 첫 검증(P0) 제안
옷 하나 범위에서: 잘 보이는 옷 240장 중 상의 60장에 대해
(1) 2D 변형 메시로 "입은 모양 → 평평한 모양" 역투영, (2) 회색 명암 분리, (3) 빈 곳은 palette 채우기,
(4) 재렌더 검사. 학습 부품은 작아서 GPU 하루 이내. 비교 대상: v4 한 장 결과, 엄격 판정.

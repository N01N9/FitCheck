# MatchDiff 상세 계획 — 범용 "같은 물체인가 / 어디가 다른가" 지도 모델 (2026-10-07)

범위(확정): 모든 물체(강체·관절체·변형체). 입력 1024px. 조명은 모델이 보정. 형상은 대략(실루엣·비율·부품 유무·배치).
마크·프린트·글자는 1024 안에서 보이는 만큼(크기별 단계). 초해상도 금지. 옷은 이후 LoRA 미세조정 대상일 뿐.

---------------------------------------------------------------------------------------------------
## 1. 과제 정의

입력: 사진 A, B (긴 변 1024), 각 대상 마스크 M_A, M_B (없으면 터치 한 점 → 내부 분할기로 생성)
출력 (B 격자 기준, 1/4 해상도 256×256 지도 + 원해상도 경계):
| 출력 | 형태 | 뜻 |
|---|---|---|
| w_BA, c | 2ch + 1ch | B 각 점의 A 대응 좌표, 확신도 |
| vis | 3-class | A 에서 보였음 / 가려짐(다른 물체) / 자기 가림·화면 밖(모름) |
| part, joints | 부품 id 지도 + 관절 그래프 | 함께 움직이는 부품, 관절 종류·축·변위 |
| D_color | 1ch, ΔE00 단위 | 고유색(반사율) 차이 |
| D_pattern | 1ch, 0~1 | 무늬·질감 차이 |
| D_mark | 1ch + 단계 | 마크·글자 차이(단계: 문자열/대략 모양/존재/모름) |
| D_shape | 1ch + 측정표 | 대략 형상 차이(윤곽 거리, 부품 비율) |
| Add / Miss | 1ch 각각 | B 에만 있음 / A 에서 보였는데 B 에 없음 |
| global | 4-class + 확률 | 같은 개체 / 같은 제품 다른 개체 / 다른 물체 / 판단 불가 |
| U_* | 각 지도의 불확실성 | 조명·해상도·가림 때문에 확신 낮은 곳 |

## 2. 모델 구조 (총 ≈1.3B, 학습 ≈0.25B)

```
A, B (1024) ──┬─▶ E_sem: DINOv3 ViT-L/16 (0.3B, 고정, 마지막 2블록 LoRA) → 64×64×1024 토큰
              ├─▶ E_fine: ConvNeXt-T 피라미드 (28M, 학습) → 1/4, 1/8 특징 (마크·윤곽·질감)
              └─▶ G_geo: 단안 깊이·법선 (상업 라이선스 모델, 고정, ≈25~100M) → 깊이·법선 1/4
                      │
 [1] 고유색 분해 I (≈20M): 각 사진 → 반사율 ρ(3ch) · 명암 s(1ch, 회색) · 조명 색 L(전역 3×3) · 반사광 h(1ch)
                      │
 [2] 대응 모듈 C (≈80M)
      · 거친 단계: 1/16 토큰 사이 전역 상관 + 6층 교차 주의 트랜스포머(768d) → 거친 흐름·확신 (A→B, B→A 동시)
      · 고운 단계: 1/8 → 1/4 국소 상관(창 9×9) + 반복 갱신(GRU, 6회) → 1/4 흐름
      · 왕복 일관성 오차 → 확신도에 입력
      · 깊이 사용: 대응된 점 쌍으로 3D 점 → [3] 에 넘김
                      │
 [3] 운동·가시성 모듈 K (≈15M + 기하 연산)
      · 계층 운동: 전역 SE(3) → 부품별 SE(3)(학습된 제안 + RANSAC 검증, 부품 수 자동) → 매끄러운 변형 잔차
      · 관절 추정: 이웃 부품 상대 운동 → 회전/미끄럼/구면/고정/분리 + 축·변위
      · 가시성: 깊이 + 추정 운동으로 B 의 점이 A 에서 자기 가림·화면 밖이었는지 기하로 판정, 다른 물체 가림은 마스크로
                      │
 [4] 정렬: A 의 ρ·특징(E_sem, E_fine)을 w_BA 로 B 격자에 당김 (vis=보였음 영역만 유효)
                      │
 [5] 비교 트랜스포머 Q (≈50M, 1/8 토큰 위 8층 512d, 입력: B 특징 ‖ 정렬된 A 특징 ‖ ρ 차 ‖ 해상도 지도 ‖ vis)
      → D_color, D_pattern, D_shape, Add, Miss + 불확실성
 [6] 마크 가지 M (≈25M)
      · 마크 후보 검출(로고·글자·인쇄 영역) 양쪽 → 대응으로 짝짓기
      · 크기 단계 선택: ≥48px / 16~48px / <16px / 안 보임
      · 단계별 비교: 글리프 특징(E_fine 1/4) 대조 + (≥48px) OCR 문자열 비교 보조 입력, 원본에서 잘라 단순 보간만
 [7] 전역 머리 (≈5M): 지도 요약 + E_sem 풀링 → 4-class
```
설계 원칙: 비교는 항상 (a) 고유색 공간에서, (b) 대응으로 정렬한 뒤, (c) 근거(vis·해상도)가 있는 곳만. 근거 없으면 '모름'.

### 3.2 쌍 생성기 (정답 지도를 '공짜로' 얻는 것이 핵심)
G1 **3D 렌더 쌍** (Blender Cycles, 1024): 같은 개체를 두 시점·두 조명·두 배경으로 렌더
   → 정답: 대응 w, 가시성(자기 가림 포함), 깊이, 반사율 동일, 부품 id
G2 **관절 쌍**: 관절 상태만 바꿔 렌더(+시점 변화) → 정답 관절·부품·"같음(구성 변화)"
G3 **변형 쌍**: 천 시뮬 전후 / 2D 매끄러운 변형(TPS·조각 아핀) → 정답 대응
G4 **실사 2D 합성 쌍**: PD12M·Open Images 물체를 잘라 변형·가림·조명·배경 바꿔 두 장 → 정답 대응·가시성
G5 **조명 쌍**: 같은 장면 조명만 바꿈(렌더) / 실사엔 명암·색온도·그림자 합성 → 정답 반사율 동일
G6 **차이 심기** (위 쌍 중 B 쪽에만, 생성 모델 사용 금지 — 기하·합성 편집만)
   - 색: 영역 색상·채도·밝기 이동(연속 크기)
   - 무늬: 텍스처 교체·간격/굵기 변경·제거
   - 마크·글자: 로고 지우기·교체·좌우반전·위치 이동, 글자 한 자 교체(합성 글꼴 렌더), 크기 단계별로 고르게
   - 형상: 부품 크기·비율 변경, 부품 제거·추가(3D 에서 부품 삭제·복제), 윤곽 변형
   - 추가물: 다른 물체 조각 붙이기
   - 다른 개체: 같은 범주 다른 3D 개체 / ABO 같은 범주 다른 제품 → global "다른 물체"
G7 **해상도·화질 단계**: 쌍을 축소(대상 크기 64~1024px)·압축·흐림 → '모름' 경계 학습
G8 **실사 양성**: ABO 같은 제품 여러 장(정답 대응 없음 → 대응은 자기지도, global=같은 제품)

## 8. 위험
- 렌더↔실사 격차 → G4·G8 실사 비중 유지, 실사 사람 판정 세트로 계속 확인.
- 차이 심기의 인공 흔적을 모델이 학습(합성 편집 자국 = 차이) → 무변경 쌍에도 같은 편집 파이프라인(크기 0)을 통과시켜 흔적을 양쪽에 둔다.
- 단안 깊이 오차 → 가시성 판정은 깊이 확신도와 함께, 낮으면 '모름'.
- 관절 부품 분할 실패 → 관절 없이 변형 잔차로도 설명되게(계층 운동의 안전망).
- 라이선스: Objaverse 개체별 라이선스·깊이 모델 라이선스·Infinigen 확인 전 사용 금지.

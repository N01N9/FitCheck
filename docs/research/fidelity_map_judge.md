# 대응 기반 충실도 지도 모델 (가칭 MatchDiff) — 설계 (2026-10-07, 범용으로 개정)

목적: **범용** — 어떤 물체든(나무·의자·컵·신발·옷) 같은 물체를 다른 각도·조명·상태로 찍은 두 사진에서
(옷은 이후 미세조정 대상: 착용샷 A ↔ 바닥에 펼친 상품 B)
(1) 부분마다 어디가 어디인지 대응시키고, (2) 그 대응을 바탕으로 색·무늬·마크·글자·형태(핏)가 같은지 부분별로 판단해
**유사도(차이) 지도**를 낸다. 평가기(엄격 판정 자동화), 학습 손실, 강화 학습 보상, 출처 통제 확산의 게이트에 모두 쓴다.

## 입력과 출력
입력: 사진 A + 대상 마스크, 사진 B + 대상 마스크 (어느 쪽이 기준인지 지정; 보통 B = 생성 결과, A = 원본)
출력 (B 격자 위, 픽셀/패치마다):
| 지도 | 의미 |
|---|---|
| 대응 장 w(B→A) + 확신도 c | B 의 이 점이 A 의 어디인가, 얼마나 확실한가 |
| 근거 지도 v | A 에서 이 부분이 보였는가(보임 / 가려짐 / 모름) |
| 색 차이 ΔC | 조명을 뺀 고유색(반사율) 차이, CIEDE2000 단위로 보정 |
| 무늬·질감 차이 ΔP | 정렬된 국소 특징의 차이 (체크 간격, 줄무늬 굵기, 니트 결) |
| 마크·글자 차이 ΔT | 로고·프린트·글자 영역의 일치 여부 + 글자열 비교 |
| 추가물 지도 Add | B 에 있으나 A 의 어디와도 대응되지 않는 고주파 내용(넥타이, 없던 로고, 없던 주머니) |
| 누락 지도 Miss | A 에서 보였으나 B 에 대응되는 곳이 없는 내용 |
| 형태·핏 차이 ΔS | 기준점(어깨·목선·소매 끝·밑단·허리) 대응으로 본 길이·폭 비율 차이, 윤곽 거리 |
요약: 항목별 점수 + 불확실성, 그리고 "판정 불가(근거 부족)" 영역.

## 구조
```
A, B ─▶ 공유 인코더 (DINOv3 ViT-L/H, 고정 또는 마지막 블록만 학습) + 고해상 CNN 가지(1/4 해상도, 글자·결)
      │
      ├─▶ [1] 대응 모듈: 거친→고운 상관(RoMa 계열 구조), 양방향 B→A, A→B
      │        · 순환 일관성 w(A→B)∘w(B→A) ≈ I 를 확신도에 반영
      │        · 변형체 사전: 국소적으로 매끄러운 장(겹침 없음 벌점) — 옷은 늘어나고 접혀도 위상은 유지
      │
      ├─▶ [2] 정렬: A 의 특징·픽셀을 B 격자로 당겨옴 (확신도 낮은 곳은 '모름')
      │
      ├─▶ [3] 조명 분리: 각 사진에서 회색 명암 + 전역 화이트밸런스 추정 → 반사율(고유색) 비교
      │
      └─▶ [4] 비교 머리들 (정렬된 쌍 위에서, 작은 트랜스포머)
               색 ΔC · 무늬 ΔP · 마크/글자 ΔT · 추가 Add · 누락 Miss · 형태 ΔS
               + 각 지도의 불확실성
```
- 글자: 머리 [4] 의 글자 가지는 고해상 CNN 특징으로 글리프 모양을 비교하고, 선택적으로 OCR 결과(문자열)를 보조 입력으로 받는다
  (OCR 은 손실로는 미분 불가 → 보상·평가에서만).
- 형태·핏: 대응된 기준점 사이 거리 비율(소매 길이/몸판 길이, 기장/어깨폭 등)을 A(착용 → 평평 환산은 대응 장이 해 줌)와 B 에서
  비교. 착용 상태의 늘어남은 대응 장이 흡수하므로 "같은 옷인데 몸에 걸려서 다르게 보이는 것"을 차이로 오인하지 않게 한다.

## 학습 데이터 — 차이를 '심어서' 정답 지도를 공짜로 얻는다
1. 대응 학습: 우리가 변형을 아는 쌍(바닥 합성, 자기 재구성 변형, 엔진 착용 쌍 중 정답 대응을 추정 가능한 것) — 정답 w, v.
2. 차이 학습(핵심): 상품 B 를 복사해 B' 를 만들며 **알려진 부분에만** 차이를 심는다
   - 색: 영역 색상/채도/밝기 이동(크기 연속값 → 정답 ΔC)
   - 무늬: 체크 간격·줄 굵기 변경, 무늬 제거/추가
   - 마크·글자: 로고 지우기, 글자 한 자 바꾸기, 다른 글꼴, 좌우 반전
   - 추가물: 넥타이·주머니·라벨·장식 붙이기 (Fashionpedia 조각)
   - 형태: 소매·기장 늘이기/줄이기, 목선 모양 바꾸기
   그리고 A 는 원래 B 의 착용/바닥 버전 → (A, B') 쌍과 정답 차이 지도.
3. 사람 판정 보정: 지금까지의 엄격 판정(v2·v3·v4·FireRed 수백 장)으로 점수→통과/실패 문턱을 보정.

## 손실로 쓰는 법 (생성 모델 학습)
- 대응 모듈은 고정, B = 생성 결과. 미분 가능한 항: ΔC(반사율 Lab 차이), ΔP(특징 거리), Add/Miss 확률, ΔS(기준점 거리).
- 근거 지도 v 로 가중: A 에서 보인 곳만 강하게, 가려진 곳은 약하게(지어내기 벌점은 Add 로 따로).
- 총 손실 = Σ 항목별 지도 × v, 실패 유형별 가중 조절 가능.
- 강화 학습 보상: 미분 불가 항(OCR 문자열 일치) 포함한 전체 점수.

## 범용화 (2026-10-07 개정) — 옷 전용이 아니라 모든 물체
목표: 각도·조명·거리·카메라·배경이 달라져도, 물체가 강체(의자)든 관절체(가위·안경)든 변형체(옷·쿠션)든
"같은 부분은 같다"고 판단하고, 진짜 다른 것(색·무늬·마크·글자·부품·모양)만 차이로 낸다. 옷은 그 위에 미세조정한다.

### 구조 변경
1. **3D 인식 대응**: 각 사진의 깊이·표면 법선을 추정(상업 가능한 단안 깊이 모델)해 대응에 쓴다.
   큰 각도 변화에서 "B 에서 보이는데 A 에서는 자기 자신에 가려 안 보였던 면"을 **기하로** 판정 → 비교 대상에서 빼고 '모름'.
2. **계층 운동 모델**(물체 종류를 몰라도 됨): 전역 강체 자세 → 부분별 강체(관절) → 국소 매끄러운 변형 잔차.
   모듈이 데이터에 맞는 단계까지만 설명하게 하고, 잔차가 크면 '모양이 다름' 증거로 쓴다.
   - 의자: 강체 단계에서 거의 다 설명 → 다리 하나 다르면 그 부분만 잔차
   - 옷: 변형 단계까지 필요 → 늘어남·주름은 흡수, 소매 길이 차이는 기준점 비율로 잡음
3. **시점 의존 외관**: 반사·광택·투명은 각도에 따라 색이 달라 보인다 → 고유색(반사율)과 반사 성분을 분리,
   반사 성분이 큰 곳은 색 판정 확신도를 낮춘다(틀린 '다름' 판정 방지).
4. **전역 판정 추가**: "같은 개체 / 같은 제품의 다른 개체 / 다른 물체" 분류 — 지도는 같은 개체·제품일 때만 의미.
5. 해상도·화질 차이(멀리서 찍은 사진 vs 근접 상품 사진): 비교 머리에 양쪽의 실효 해상도를 입력해,
   원본이 흐려서 판단할 수 없는 미세 글자는 '모름'으로.

### 범용 학습 데이터 (상업 가능성 확인 필요 항목 표시)
| 종류 | 후보 | 라이선스(확인 필요) | 쓰임 |
|---|---|---|---|
| 3D 물체 렌더링 | Objaverse(ODC-By 전체, 개체별 CC0/CC-BY 만 선별), Google Scanned Objects(CC BY 4.0), ABO 3D(CC BY 4.0) | 개체별 확인 | 임의 각도·조명 렌더링 → 정답 대응·가시성 공짜 |
| 실사 다시점 | 자체 촬영 영상(턴테이블, 휴대폰 회전) | 자체 | 렌더링↔실사 격차 메우기 |
| 실사 물체 사진 | PD12M·Open Images(CC BY) 물체 마스크 | 공개 도메인·CC BY | 2D 변형·가림·조명 합성 |

제외: CO3D(CC BY-NC), MVImgNet(별도 비상업 조건) — 비상업.

### 크기·속도 (범용)
- 인코더 DINOv3 ViT-H(0.84B, 고정) + 깊이 모델(0.1~0.3B, 고정) + 대응·운동 모듈(0.15B) + 비교 머리(0.1B)
  → 합계 약 1.2~1.4B, 학습 몫 약 0.25~0.3B. 512px 두 장 H100 약 0.1~0.2초.
- 옷 미세조정: 비교 머리·변형 모듈만 LoRA/부분 학습(수만 쌍).

## 기계적·구조적으로 움직이는 물체 (2026-10-07 추가)
대상: 접이식 의자, 노트북 열림/닫힘, 가위·안경, 서랍·미닫이, 자동차 문, 바퀴, 관절 인형·로봇, 망원(늘어나는) 구조,
떼었다 붙이는 부품(뚜껑·렌즈 캡). 판정: "같은 물체가 **구성(configuration)만** 바뀐 것"인지, "부품·모양·외관이 **실제로 다른** 것"인지.

### 구조 추가: 부품·관절 추론 모듈
1. **운동 분할**: 대응 장을 강체 운동(SE(3))별로 묶어 부품으로 나눈다 — 함께 움직이는 점들 = 한 부품.
   깊이로 3D 점을 만든 뒤 RANSAC 류 다중 모델 맞춤(학습된 제안 + 기하 검증). 부품 수는 정하지 않고 자료가 정한다.
2. **관절 그래프 추정**: 이웃 부품 사이 상대 운동을 해석 → 관절 종류(회전·미끄럼·구면·고정·분리)와 축·범위.
   예: 노트북 "화면 부품이 경첩 축을 중심으로 100° 회전", 서랍 "레일 방향으로 30cm 이동".
3. **부품 기준 좌표에서 비교**: 각 부품을 자기 기준 좌표로 되돌린 뒤(구성 변화를 빼고) 색·무늬·마크·글자·모양을 비교.
   → 구성만 다르면 차이 지도는 비고, 관절 그래프에 "무엇이 어떻게 움직였는지"가 남는다.
4. **구조 일치 검사**:
   - 부품 수·연결 관계(위상)가 같은가 → 부품 누락·추가·다른 부품
   - 관절 종류·축이 같은가 → 같은 경첩이 다른 방향으로 돌아갔다면 다른 구조
   - 운동이 그럴듯한가(축 주위 회전, 범위 안) → 범위를 벗어나면 '파손/변형' 후보
   - 분리 가능한 부품(뚜껑)이 떨어져 있으면 '분리됨'으로 표시하고 같은 것으로 셈(설정 가능)
5. 운동 계층(강체 → **관절** → 변형)의 관절 단계가 이 모듈. 천 같은 변형체는 관절로 설명 못한 잔차를 변형 단계가 흡수.

### 출력 추가
- 부품 분할 지도(A·B 각각, 같은 부품끼리 같은 번호)
- 관절 그래프 + 구성 변화 설명(관절별 회전각·이동량)
- 판정: 같음(구성만 변화) / 같음(분리 부품 상태만 다름) / 다름(부품·위상·외관) / 판단 불가 + 근거 지도
